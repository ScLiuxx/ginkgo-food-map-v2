2026-11-22起移除全部窗口资料、管理、相册和点评接口。原窗口地址不提供兼容跳转或恢复接口，按未知地址返回统一404（仍遵守认证边界）。食堂改用[餐厅资料](restaurants.md)与[直接点评](reviews.md#publish)协议；不再返回windowId。

旧窗口及关联数据的永久清理、媒体物理删除与发布验收见[迁移计划](../plans/remove-canteen-windows.md)。本页仅供历史链接解释变更，不属于现行接口索引。
