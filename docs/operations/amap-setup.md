# 高德地图环境配置

目前本地已完成真实高德底图、初始化安全代理、100点位、缩放自动查询及悬停卡片验证。未配置环境时/map会提示未配置并保留目录；生产Nginx代理和手机App唤起尚未验收，本地测试不能代替线上验收。

1. 在高德控制台为本应用申请Web端（JS API）Key，核对账号用途、配额及开发/生产域名白名单。不要使用Web服务Key替代JS Key，不将安全密钥发送到聊天或纳入Git。
2. 将frontend/.env.example复制成被忽略的frontend/.env.local，填写VITE_AMAP_KEY和AMAP_SECURITY_JS_CODE；设置VITE_AMAP_SERVICE_HOST=/_AMapService。只有浏览器JS Key和代理路径允许进入VITE变量，安全密钥变量禁止添加VITE_前缀。
3. 开发服务器已在config/amapProxy.ts实现同源安全代理，Vite仅在服务端读取AMAP_SECURITY_JS_CODE并附加到固定高德上游请求。仅允许GET、地图初始化/样式、精确的/v3/assistant/coordinate/convert坐标转换及/v3/place/text餐饮关键词搜索路径；覆盖客户端Key/安全密钥，不允许任意URL或周边/详情等其他搜索路径。地点搜索关键词1–100字符、page为1–100，代理固定types=050000、offset=10、extensions=base、city=成都市、citylimit=false。单次上游超时8秒、错误输出固定代码，不记录带密钥URL。按[高德官方方案](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)配置生产Nginx时需独立提供安全密钥及对应路径/参数限制，Vite开发代理不会进入生产静态构建，不能只部署dist便认为生产代理已生效。
4. 本地修改环境变量后重启Vite；生产环境需在构建时提供浏览器配置，安全密钥仅在运行代理配置中提供。禁止打印完整环境或带密钥的转发URL。
5. 使用真实餐厅验证底图、落点、移动后自动查询、悬停、失败降级及手机布局；确认高德标识/版权不被面板遮挡。测试查询接口与真实SDK分别记录证据。浏览器本人定位仍需要HTTPS和授权，当前地图查询无需本人定位。

SDK能力以[JS API 2.0参考](https://a.amap.com/jsapi/static/doc/index.html)为准；跳转使用[官方URI地点入口](https://developer.amap.com/api/uri-api/gettingstarted?type=spa)：只传GCJ-02目的地坐标、店名、coordinate=gaode、src=ginkgo及callnative=1，不传固定起点或本站定位坐标，由高德处理定位、交通方式和路线。按钮为“在高德中打开”。移动端尝试唤起App，电脑使用高德地点页；按用户要求，本轮跳过线上及真机外部验收，不承诺已验证自动定位或App唤起。

地点搜索使用AMap.PlaceSearch插件，复用既有Web端（JS API）Key，不额外索要Web服务Key；当前本地已通过真实搜索200/OK验收，账号权限/配额仍以控制台为准。关键词停顿500毫秒后发送给高德，优先成都但不强制锁城，不传当前地图边界或用户精确定位；SDK只返回基础地点，不绑定自动地图/结果面板。SDK加载、插件和搜索合计15秒上限，序号与取消信号拦截迟到响应；错误提示不输出原始URL或凭据。结果仅页面内存保留，不批量导入；本站匹配每页最多10个地点、3路并发，各读取100米矩形内最多100条候选，唯一同名80米内才确认匹配，失败或候选截断显示待核实。地点名和地址差异不能当成权威的未收录证明。

“我的位置”在“回校区”下方，只在用户点击后调用浏览器getCurrentPosition一次，不启用watchPosition或自行使用IP估算。需HTTPS安全上下文及网站/系统定位权限；localhost和127.0.0.1可本地开发。8秒设备定位超时，包含授权等待及转换的总等待上限20秒；拒绝、不可用、超时、坐标转换失败分别提示，重复点击等待期间禁用，离开页面忽略迟到结果。浏览器可能使用系统、Wi-Fi或GPS等位置服务，桌面定位并不保证可用或准确。

定位结果按WGS84交给AMap.convertFrom(..., 'gps', ...)转换为GCJ-02，显示独立蓝点及本次获取时间、浏览器报告的精度；装饰光晕不表示真实精度范围。地图移至该点后复用视口查询，并不新增附近半径搜索/距我排序，“距校区”仍按清水河计算，高德跳转不传固定起点。刷新或离开地图清除位置，不绑定学校邮箱、不写入业务数据库或浏览器持久存储。高德转换会收到坐标，地图瓦片和本站范围查询也会暴露区域；开发代理会处理转换坐标，基础设施访问日志需避免记录该路径查询串，不能承诺位置从不离开浏览器。

本地验收证据位于仓库外D:/eat/.codex-backups/amap-live/：facts.json、desktop.png及mobile.png。只记录去查询参数后的请求路径和结果，不保存凭据。缩放过程中SDK取消旧瓦片请求属于正常行为，不将其当作业务写入或导航失败。
