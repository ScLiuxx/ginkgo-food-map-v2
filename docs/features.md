# 泥电美食地图功能说明

泥电美食地图帮助大家查找餐厅和食堂窗口、参考点评并分享用餐体验，支持电脑和手机浏览，不提供下单、支付或配送。

本文介绍当前已实现的功能，线上可用内容以实际发布版本为准。全站评分统一按五分制展示，满分5分。普通餐厅的综合口碑分结合四维评分与评价人数计算，综合排序直接采用同一个分数；无评价显示待评价。食堂和窗口保留既有评分口径。

## 找餐厅

- **搜索与浏览**：按店名、地址、分类或标签查找餐厅，翻页浏览结果，列表最多可浏览前10000条。列表资料与评分可能稍晚更新，进入详情可查看当前资料。普通餐厅分为小吃快餐、中餐地方菜、火锅串串、烧烤烤肉、香锅烤鱼、国际美食、甜品烘焙、饮品和其他美食九类。
- **筛选与排序**：首页可按餐厅或食堂、堂食或外卖、人均预算筛选，隐藏停业店铺，并按综合口碑分、热度或距离排序。热度按点评条数排列；距离可选择距清水河、距沙河或距我最近，只有距我需要主动定位。校区距离只是排序，不自动限制5公里。资料未确认的店铺不会被当作满足相应条件。
- **搜索故障兜底**：搜索服务暂时无响应时，会在等待超时后尝试用数据库继续查找餐厅，避免一直等待；备用查询的匹配结果可能有所不同。
- **附近餐厅**：允许定位后查看距离和附近餐厅，也可更新位置；拒绝定位仍能继续浏览。距离为直线距离，不是步行路程，位置不保存到账号。
- **帮我选一家**：在独立弹窗内先选条件，再随机给一家普通餐厅，不受首页搜索和筛选影响。每次进入所有条件都不预选，选齐后才能开始；支持换一家、上一家、改条件、详情和导航。完整规则见[选店计划](plans/restaurant-picker.md)。
- **餐厅详情**：店铺资料和同学点评分区展示，突出店名、总评分和点评正文；写点评、收藏、补充纠错集中操作。查看地址、人均消费、经营状态、用餐方式、标签、评分、点评及商家相册，可放大照片或在高德中打开地点。缺少的资料显示未知或暂无。

## 帮我选一家

- 条件以分组按钮展示，已选项用橙色区分；结果突出店名和“换一家”，没有封面时只显示简短占位。手机条件区域可滚动，提交按钮保持可见。
- 选择清水河附近、沙河附近或我附近，再选直线距离1、3、5公里；我附近需要主动定位成功。人均预算可选15、30、50、100元以内或不限；最低评分可选不限、3分、3.5分、4分及以上；类别单选或不限，用餐方式为堂食、外卖或不限。六项均需主动选择，包括“不限”。
- 评分按五分制综合口碑分筛选：选择门槛时排除暂无评分和不达标的店，不限评分则允许新店参与。先筛选再等概率抽取，没有结果时提示修改条件，不会自动降低评分要求。
- 同时满足条件且未标注停业的普通餐厅等概率参与；食堂不参与。明确预算时排除人均未知的店，明确用餐方式时只选确认支持的店，位置待补的店不会算作附近。
- 本轮已展示的店不会再次抽中，“上一家”回看不消耗候选；回看时“下一家”先前进到已看过的下一项，走到历史末尾才继续抽新店。全部看完可重新抽一轮或修改条件，只有一家会提示，没有符合条件的店时不会自动放宽要求。
- 修改条件保留已填值，确认后重新开始并清空本轮历史，取消修改回到原结果。主动关闭后重新进入从头选择；查看详情后返回则恢复这一轮的条件、店铺与历史，不当作主动关闭。
- 展示真实商户封面、评分及点评条数、人均和直线距离，缺失信息如实显示。换店、回看和详情返回时复核当前资料，不再符合条件的店不提供详情/导航操作；资料核对失败可重试，不冒充没有候选。历史仅保存在本次页面会话内，刷新后重新开始。

## 地图与导航

- 移动、缩放地图查找当前范围内的餐厅，点选店铺查看信息、进入详情或交给高德导航。电脑端使用侧栏列表；手机端底部默认露出列表顶部，上拉停在半屏或全屏，下拉收起，无需点击“查看列表”。列表覆盖固定尺寸的底图，展开不会缩小查询范围或减少候选餐厅；全展开时显示完整列表。列表独立滚动，滚到顶部再下拉才收起；也可点按手柄或用键盘调整面板。
- 手机顶部保留搜索、综合排序、热度、距离和筛选；分类、预算、餐厅类型、用餐方式与隐藏停业收进筛选弹层，确认后一起应用，取消不改变条件。搜索与底部导航固定，面板停在导航上方，选店卡片和列表共用底部区域，保留真实地图版权。
- 地图先圈定找店范围，关键词、分类、预算等条件只筛选该范围内的本站店铺；移动或缩放地图后保留条件，在新区域重新查找。地图标记与列表卡片共用同一批店铺，卡片可连续滚动浏览，点击任意店铺可定位并查看详情。需要全站搜索时可使用首页；投稿页仍可搜索高德地点辅助填写资料。
- 支持查看自己的位置、回到校区，以及将目的地交给高德查看路线。导航方式由高德选择，手机打开 App 的效果以实际设备为准。
- 每个范围最多展示100家店铺，地图和列表使用相同集合，明确显示区域内总数与当前展示数量；更多店铺可通过放大或移动地图查找。地图尚未加载时等待有效范围，也可返回首页浏览；更新失败时两边均保留上次结果并提示重试。
- 密集店铺合并为带数量的圆标，点击后放大并在新范围继续查找，放大后逐步展开单店；选中的店铺单独高亮。坐标重合或已放大到最大时，可从聚合店铺名单中直接选店。聚合数字只统计当前已加载的店铺，与列表使用同一批数据，不代表整个区域的全部店铺数量。
- 电脑和手机点选餐厅时可以放大定位查看，但保留原来的列表、餐厅数量与查询范围；用户主动拖动或缩放地图后，再按新范围更新结果。
- 本次打开网站期间，从店铺详情或其他页面返回地图，会恢复地图位置、缩放、搜索筛选、主动选中的店铺、列表滚动位置和手机面板展开状态。从地图点击“查看详情”后，详情页显示“返回”，点击即可回到刚才的地图选店状态；详情加载失败或店铺已删除时也能返回地图。返回后重新读取店铺资料，更新失败仍保留上次结果；已不符合条件的选店会清除。浏览记录只保存在当前页面会话内，刷新网页后重新开始。

## 食堂与窗口

- 在首页筛选食堂，食堂资料与窗口列表分区展示；进入食堂后浏览窗口，多楼层时可切换楼层，查看窗口介绍、参考人均、评分和点评；返回食堂时保留楼层选择。
- 窗口不设美食分类，资料由管理员统一维护，用户可发布窗口点评和点评照片。
- 窗口列表展示封面，详情可浏览窗口相册、切换照片和查看大图；没有照片时明确提示。
- 普通餐厅和窗口分别评分。食堂总分取营业且已有评分窗口的平均分，各窗口权重相同；没有评分时显示待评级。
- 停业窗口保留历史内容，停止接收新点评。食堂页只展示窗口，不提供食堂整体点评入口。

## 点评与互动

- **写点评**：登录后通过与首页同款的搜索框查找店铺，输入关键词后才加载结果，再选择普通餐厅或食堂窗口；没有搜索结果或滑到结果列表底部时，可点击“添加餐厅”进入添加页。选好后填写味道、性价比、服务、环境评分、推荐态度和正文，最多附5张照片。图片支持预览、移除和失败重试。
- **推荐态度**：正式点评支持“推荐／一般／不推荐”，每次打开表单均不预选，发布前必须明确选择。店铺、窗口、历史点评、个人主页及回复通知中的原点评均保留作者所选态度。
- **新店附带点评**：添加普通餐厅时，可在填写店铺资料后进入独立的点评步骤，最终一次提交；审核前内容仅本人可见，管理员只审核店铺资料，通过后自动以原作者身份发布点评与照片并计入评分。任一步失败整体失败，重复审核不重复发布或奖励；待审修改、驳回重提和撤回均已接通。使用入口见下方“商户投稿与纠错”，完整规则见[实施计划](plans/restaurant-review-submission.md)。
- **看点评**：游客也可阅读。每人默认展示最新点评，可展开历史、查看照片大图和回复；支持翻页、刷新、默认排序和按时间排序。
- **评分规则**：同一人对同一家店或窗口仅最新有效点评参与评分，历史不重复计分；页面展示评分、评价人数和点评条数。“一般”与其他态度一样按所填四维评分计分。推荐态度仅在单条点评展示，不汇总推荐率，也不影响排序、筛选或榜单。
- **回复与点赞**：登录后可回复点评，点击爱心点赞或取消点赞，不能给自己点赞；可删除自己的回复。
- **删除点评**：确认后可删除自己的最新或历史点评，也可取消操作。删除后相关照片和回复一并移除；删除最新点评后，上一条有效点评接替计分。删除不能恢复。
- **举报**：登录后可举报他人的点评或回复，选择原因并可选填说明；同一用户对同一内容只能举报一次，重复提交会返回原记录。举报不会立即隐藏内容，管理员后台处置尚未开放。
- **收藏与关注**：可收藏普通餐厅或食堂、取消收藏，关注或取消关注其他用户，并查看获准公开的收藏、关注和粉丝名单。

## 补充店铺与纠错

- 搜索未找到店铺时可提交新店，在已有餐厅详情可进入“补充 / 纠错”；均需登录，管理员审核通过后才公开生效。
- 首页没有符合条件的店铺，或翻到列表最后一页时，会显示“添加店铺”入口；点击进入现有投稿页，并保留搜索关键词。加载中或读取失败时不会显示末页提示。
- 可填写或修正店名、分类、餐厅类型、人均消费、堂食或外卖、地址、位置、经营状态和标签；搜索高德门店后可自动填入店名、地址和位置。
- 每次申请最多附5张图片，可查看已有商家照片；通过审核的新图片加入商家相册。
- 新增普通餐厅分两步：先填写店铺资料与店铺照片，选择“仅提交店铺”或“下一步，写点评”；点评页显示店名和地址，填写四维评分、推荐／一般／不推荐、5–500字正文及最多5张点评照片，态度无默认选择。进入点评页不会提交申请，返回店铺资料保留所有字段和两类照片，最后一次提交店铺与点评。返回后选择仅提交店铺不会保存未提交的点评。食堂需收录后评价具体窗口。店铺审核通过后点评自动发布，审核前正文和图片仅本人可查看。
- 管理员确认投稿店铺已经收录时，申请显示“店铺已收录”并关联已有店铺；如有附带点评，会自动发布到该店，原店铺资料和店铺投稿附图保留供核对。本人记录可查看处理结果和关联店铺，消息中也会显示该结果。
- 在“我的投稿 / 纠错”查看待审核、已通过、已驳回和已撤回记录，以及原投稿、审核结果和驳回原因。待审核申请可整体修改或撤回；被驳回后可带入原内容修改并重新提交，系统生成一条新的待审核申请并保留原驳回记录与两者的关联。已通过、已驳回或已撤回的申请不能直接修改。用户不能直接修改正式店铺资料。
- 本人申请详情可查看未发布点评的评分、态度、正文和私有图片。修改或重提会带入原内容与图片，已有附带点评可修改内容但不能整条移除；撤回后内容保留，不能继续编辑或重提。已重提的原记录提供后续申请入口，点评发布后显示回执和店铺入口，不保留一份私有正文副本。

## 账号与个人中心

- **账号**：使用学校学生邮箱（@std.uestc.edu.cn）接收验证码注册，支持使用用户名或注册邮箱配合密码登录、忘记密码重置及退出登录。注册成功后自动登录，重置密码后需重新登录。
- **我的内容**：集中查看自己的点评与历史、收藏、投稿和纠错记录。点评和收藏使用统一卡片列表，可刷新、进入店铺、写点评或取消收藏；点评保留互动与本人删除入口。
- **我的页面**：集中展示用户名首字头像、简介、关注、粉丝、获赞和成长进度，可进入个人主页、成长规则及常用功能；手机上功能入口单列排列。
- **个人主页**：登录后可查看用户名首字头像、简介、等级、关注、粉丝和获赞数，切换点评与收藏；点评突出店铺和正文，收藏可直接进入店铺，本人可取消收藏。数量以已读取的列表为准，收藏与关注名单仍受隐私设置限制。
- **账号设置**：按个人资料、隐私设置和账号安全分区，查看绑定邮箱、编辑或清空最多100字的简介、重置密码或退出登录。通过独立开关设置收藏、关注和粉丝名单是否向其他登录用户公开；这三类名单默认仅本人可见，保存失败可重新读取核对。
- **举报内容**：登录后可举报他人的点评或回复，选择广告、辱骂、色情低俗、违法违规、隐私、无关内容或其他原因，并可补充最多200字说明；同一内容重复举报按已提交处理。举报不会立即隐藏内容，由管理员核查后驳回或永久删除，结果通过系统消息告知举报者。
- **成长等级**：查看当前经验、等级、升级进度及距离下一级所需经验，可刷新查看最新数据；页面列出奖励数值和简要规则。首次点评某家餐厅或窗口得5经验，新店投稿通过得20经验，纠错通过得10经验；同一奖励不重复领取。点评获赞每次得1经验，每日最多5点，同一点赞者每天最多贡献1点。普通删评或取消点赞不扣回已获得经验。

## 消息与公告

- 分类查看收到的赞、点评回复、新增关注，以及投稿审核结果、举报处理结果和全站公告。
- 点击消息查看对应内容，可标记单条、整类或全部已读，也可删除自己的单条消息；删除消息不会删除原点评或申请。
- 点赞、评论和公告可打开详情弹窗；评论同时展示原点评和回复，长内容可滚动阅读，点评及回复详情可进入对应店铺。举报结果通知只展示“内容已删除”或“未认定违规”，不跳转到已失效内容。
- 有未读消息时导航显示红点，新消息、已读和删除操作会自动更新提醒；仅打开消息列表不会清空未读。

## 管理员功能

管理员使用统一登录页进入工作台，日常浏览和点评需切换普通账号。

- **店铺管理**：搜索、筛选、翻页查看店铺，直接新增或修改资料，维护分类、餐厅类型、堂食及外卖情况，删除店铺或按编号恢复。
- **窗口管理**：在食堂下新增、编辑窗口，维护名称、楼层、介绍、参考人均和经营状态，支持停业、删除与恢复；窗口不能移到另一食堂。保存窗口后进入“照片管理”上传或删除照片，每个窗口最多5张，首张作为封面，删除首张后下一张接替。
- **投稿审核**：按状态、店名或申请编号查找申请，查看原资料、变更和附图，修正后通过或填写原因驳回。新店申请提供“店铺已收录”，搜索并核对已有店铺后选择关联，结束申请并自动发布附带点评，避免再建一家重复店铺；不发新店投稿经验，正常点评经验按原规则计算。支持连续处理下一条，并查看已处理结果。
- **公告管理**：向全体用户发布公告，查询公告记录和详情，撤回已发布公告。
- **举报处理**：按状态查看举报列表和详情，包括提交时的正文快照、举报原因和说明；对同一内容的多份举报可一并驳回并填写备注，驳回不会删除或隐藏内容；确认违规后可永久删除点评或回复，关联回复、图片、商户评分和获赞按现有规则同步处理，同一内容的多份举报一并结案。处理结果会向每位举报者发送一条系统消息，说明内容已删除或未认定违规；账号处罚尚未开放。

## 当前范围与未开放功能

- **近期推荐榜**：首页搜索框右侧可进入榜单，切换清水河／沙河及近7天／近30天，查看前20名餐厅的封面、对应周期推荐分和评价人数，点击进入餐厅详情。至少3人评价且近期口味均分达到4分才可上榜，排序同时参考其他评分及人数；不足20家时少展示或空榜。显示更新时间，准备中、暂不可用或加载失败时可重新加载。正常约每小时更新，更新失败暂时沿用旧榜，过期结果停止展示。
- 本地已收录约9500家周边餐厅基础资料和12条食堂记录，学校食堂尚未收齐，窗口明细仍需补充；营业、价格等资料仍需持续核实，线上数据以实际发布为准。
- 本地沙河榜单已用20家店铺的122条模拟点评完成展示联调。模拟点评明确标注为演示，不能作为真实消费口碑或线上数据；本地可直接切换沙河周榜、月榜并进入店铺查看。
- 尚未开放：独立点评照片墙、贡献榜和全站统计、独立区域选择、管理员直接上传普通餐厅或食堂相册、商家相册删除或重排、窗口相册手动排序及菜品管理、完整回收站、数据导入导出和页面内备份恢复。
- 暂不提供：用户提交窗口资料、点评编辑、账号处罚与申诉、私信、@提醒、拉黑、指定用户公告、改名、换绑邮箱和头像上传。
- 离线使用、安装为应用及登录设备管理尚未开放；跨设备实际使用和线上导航、定位等仍需验收。
