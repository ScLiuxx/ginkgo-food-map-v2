# 高德地图找店实施计划

更新：2026-11-12。地图找店以地图范围为核心，当前行为见[功能说明](../features.md#地图与导航)，接口契约见[详情与地图点位](../api/restaurants.md#detail-map)，验证与运行状态见[开发记录](../development.md)。

## 当前范围

- 地图使用高德JS API 2.0和GCJ-02坐标。拖动或缩放结束后300毫秒防抖查找最终视口；关键词、分类、预算、经营状态、类型、用餐方式和距离条件均作用于该范围，不自动扩大到全站。
- 单次范围接口同时返回有序点位和公开卡片资料，两边使用相同店铺集合。无额外目录分页或逐店详情补查，卡片在侧栏或底部面板内连续滚动。电脑和手机点选都只定位、高亮及展示卡片，保留原候选范围；用户主动浏览地图后再查询新范围。
- 每批最多100家，完整匹配数量与当前展示数量分开提示，超限时引导放大或移动地图。密集点位按屏幕距离聚合为数量圆标，点击逐级放大；重合坐标或最大缩放时可从成员名单选店。选中店铺独立高亮，聚合数字只统计本批成员，100家上限不代表完整区域分布。
- 地图页仅展示本站店铺。全站查找使用首页；高德地点搜索继续用于投稿、纠错及选址组件，不混入地图页的本站候选集合，也不自动入库。
- SDK未给出有效视口前等待地图，不回退为全站目录；SDK失败可重试或返回首页。接口失败同时保留上次点位和卡片并标明未更新；过期响应即使忽略abort也不能覆盖新范围。
- 电脑使用侧栏，手机使用收起、半屏、全屏三档拖动面板。固定底图由面板覆盖，上拉、下拉和卡片滚动不改变查询范围；全屏列表覆盖地图，品牌、底栏和原生地图版权保持可访问。
- 路由离开前在会话内保存图面中心/缩放、独立候选范围与同批资料、筛选、固定选店、列表滚动及手机面板停靠位；返回立即呈现并按保存范围重新验证。地图实例正常销毁与重建，恢复时不自动用点选后的局部图面覆盖候选范围，真实手势后才恢复范围查询。仅恢复主动选店，不恢复临时悬停；刷新页面不保留浏览记录，预览不读写真实记录。
- 地图详情链接使用`from=map`明确来源，详情导航显示“返回”；正常入口回到原地图历史条目，直达或新标签页无对应历史时替换为站内`/map`。来源只接受固定标记，故障/缺失页也指向地图，其他入口保留首页或父食堂导航。

## 导航、位置与配置

- 外部导航由用户点击HTTPS `https://uri.amap.com/marker`触发，只传目的地、名称、`coordinate=gaode`、`src=ginkgo`及`callnative=1`；定位、起点和路线由高德处理。站内不新增路线规划、时间估计或导航起点选择。
- 本人位置仅在主动点击时申请浏览器定位，再由高德从WGS84转换GCJ-02；不绑定账号或持久化。校区距离采用既有固定GCJ-02参照点，距离排序与范围上限沿用既有服务端规则。
- `needsLocation=true`、缺失或非法坐标不进入地图候选，也不能生成坐标导航链接；详情仍可通过首页访问。未知位置不补校园坐标，无评分不补虚构分数。
- SDK按地图页面懒加载，使用共享Promise、超时和可控重试。切换页面销毁地图及监听并取消请求；Key、安全密钥和生产配置不进入Git。生产安全代理、HTTPS及手机唤起要求见[配置说明](../operations/amap-setup.md)。

## 数据与查询边界

复用restaurant模块的范围接口，不新增表或迁移。MySQL保留业务真值，查询沿用既有ES关键词检索、版本回查、SQL降级及熔断；不新增地理服务或中间件。

聚合仅属于前端渲染：使用高德公开坐标投影取得屏幕位置，每轮合并重心距离最近且不超过52像素的两组，直到组间分离。当前每批上限100家，直接比较即可；无需新增插件加载链或后端聚合接口。缩放结束后重算，点选定位的候选范围锁定仍独立生效，悬停未改变分组时保留按钮和焦点。后续若扩大加载规模，应重新评估算法成本及服务端区域聚合，不能直接沿用本实现宣称覆盖全量数据。

- SQL路径的完整数量、同批店铺、标签及封面在一个RR只读事务内读取。
- ES关键词路径沿用整批版本核验；不以SQL LIKE再次过滤分词命中，发现变化时整次回退SQL。
- 点位从同一批公开卡片资料派生，ID与顺序一一对应；封面批量读取元数据，不访问OSS。接口保持100家上限，保留原points字段以兼容已有调用。
- 响应内集合一致不等于跨请求强一致；ES仍存在同步与refresh窗口。具体入参、状态码及响应字段只在API文档维护。

## 验证与交付

- 后端使用随机MySQL隔离库覆盖视口边界、筛选、公开字段、同批ID/顺序及100家截断；ES专项另验证版本回查后的点位与卡片一致。
- 前端覆盖范围约束、防抖、取消与乱序、错误保旧和重试、无视口等待及卸载；SDK事件测试区分点选定位与主动浏览。聚合覆盖近远点、缩放拆分、数字间距、选中独立、同坐标/最大缩放名单、悬停焦点保留及筛选清理。
- 返回恢复覆盖实际路由卸载/重建、相机与查询范围分离、共享筛选恢复、刷新失败保旧、失效选店清理、滚动保留与主动筛选重置，以及预览/新会话隔离。真实浏览器检查详情返回和手机全屏列表经首页往返，避免把DOM隐藏或浏览器滚动锚定误当作保存成功。
- 浏览器分别记录真实后端、真实SDK与API夹具的验证范围，检查1440/390/320像素、列表滚动、面板展开、点选高亮、搜索后移动地图及溢出；不把夹具当作生产数据验证。
- 阶段变更与最终验证写入development，产品能力写入features，现行接口写入api；不自动提交、合并或发布。
