# 社区前端接入状态

2026-11-07。按用户确认的个人中心、个人主页、消息及设置示意图改造，沿用白底、浅灰分隔、暖橙色和现有五栏导航。本文只记录接入程度，不重复定义[社区业务规则](community-rules.md)。后端契约以[API](../api.md)为准。

## 当前页面

| 入口 | 当前可用程度 |
| --- | --- |
| `/account` | 真实用户名、本人简介、等级、经验和升级进度；互动人数尚未接通，显示“—”。四个功能入口可进入对应页面。 |
| `/account/growth` | 真实等级、经验、升级进度和手动刷新；门槛由服务端返回，最高级不虚构下一等级。 |
| `/account/reviews` | 已接入[本人分页查询](../api.md#105-本人点评按店铺分组)，按店展示最新有效点评，历史、照片、回复及本人删除复用原有能力；停业可见、删除店铺排除。删除成功回第一页，普通删评保留经验；失败不模拟成功。 |
| `/account/favorites` | 真实本人收藏分页，失效记录保留并可取消；故障、空列表和失效店铺分开显示。 |
| `/account/contributions` | 已接入[本人申请列表、详情及私有附图](../api.md#16-本人投稿与纠错记录)，按提交时间倒序分页，支持状态筛选，分别展示原提交、实际通过内容及驳回原因。提交新店进入既有真实流程；后端已提供待审修改/撤回与驳回重提接口，前端交互入口待接入。 |
| `/account/settings` | 用户名只读；已接入[本人资料GET/PATCH](../api.md#15-本人资料与简介)，显示脱敏邮箱，简介可保存及清空，失败保留草稿；现有密码重置与退出可用。三个列表隐私设置仍待后端，控件禁用。 |
| `/account/following`、`/account/followers` | 名单待开放，不伪造人数、名单或隐私授权。 |
| `/users/:id` | 游客仅显示登录入口；展示被查看者真实用户名、简介、等级、获赞、按店分组点评及历史，不显示邮箱；收藏页每次请求核验公开权限，私密拒绝不显示计数或记录。 |
| `/messages`及分类地址 | 首页显示独立的系统摘要与系统/评论未读数；SYSTEM与COMMENTS分别分页及分类全部已读，首页处理全部。审核通知打开本人申请；评论通知保存单条已读后精确展示原点评和回复，失效目标不显示正文。获赞分类及内容定位已接通，关注分类及已读后主页跳转已接通；各分类可确认删除本人单条已读/未读消息，删除成功回第一页重读，源业务不受影响。 |
| 店铺、点评和回复 | 点评/回复点赞、取消与真实计数已接通；餐厅/食堂收藏按钮已接入真实状态及收藏/取消；用户名跳转个人主页，游客先登录。举报弹窗明确无法提交，原因分类及提交接口尚未确定和接入；单独删除本人回复已接入二次确认、失败重试与成功后从头刷新，换号或卸载不接受旧身份回执。 |

身份、成长或本人资料请求不能跨账号复用，页面退出或切换账号时取消旧请求、清除旧快照及简介草稿，迟到的保存回执不能影响新账号。读取错误显示重试，不用零经验或空简介兜底；简介保存失败保留编辑内容供重试。登录回跳只允许已知站内路径，保留管理员优先进入工作台的规则。
